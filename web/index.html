Antes da instalação o arquivo é validado com SHA-256 e uma cópia de segurança do código é criada. Books, fotos, histórico, configurações, Bases QField e ambiente Python não são apagados. O servidor será reiniciado automaticamente.

Execução e dados

O Book Poda abre em http://localhost:8765, funciona somente neste computador e mantém o histórico em Dados/books.sqlite3. As camadas QField são lidas de arquivos locais e carregadas apenas conforme a região visualizada. Para atualizar as bases posteriormente, é necessário reconstruir os tiles correspondentes.
